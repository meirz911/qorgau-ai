# Qorgau AI 🛡 — антифрод для банковских переводов

**ITU HACKATHON-2026 · FinTech case** · «қорғау» — защищать

> Останавливаем мошенничество **до** того, как деньги ушли — и объясняем клиенту почему, его языком.

## Проблема
За 11 месяцев 2025 года в Казахстане зарегистрировано **26,3 тыс.** интернет-мошенничеств (**+20,3%**), ущерб **11,2 млрд ₸** (Генпрокуратура РК); по оценке МВД, совокупные потери превысили **29 млрд ₸**. Самые частые схемы — телефонное мошенничество (22%), фейковые инвестиции (19%) и дроп-карты (19%). Источники — в [JURY_QA.md](JURY_QA.md).

Главная причина потерь клиентов в Казахстане — не взлом, а **социальная инженерия**: звонок «из службы безопасности банка», «безопасный счёт», AnyDesk, предоплата на OLX, «инвестиции». Клиент сам подтверждает перевод — классический антифрод видит «легитимную» операцию. Деньги уходят на **дропов** и за минуты выводятся.

## Решение
Риск-движок, который оценивает каждый перевод за < 1 мс и принимает одно из трёх решений:

| Score | Решение | Что видит клиент |
|---|---|---|
| < 35 | **ALLOW** | Ничего — честные клиенты не страдают |
| 35–69 | **CHALLENGE** | Экран «Похоже на мошенничество»: причины, 3 вопроса, пауза 15 с, кнопка «Отменить» главная |
| ≥ 70 | **HOLD** | Перевод приостановлен, звонок с официального номера |

### 4 слоя сигналов (↔ 4 пункта задачи кейса)
1. **Поведение клиента** — сумма vs норма (z-score), новый получатель, время, частота.
2. **Контекст сессии** (SDK мобильного приложения) — *идёт звонок*, звонящий не в контактах, открыт AnyDesk/RustDesk, новое устройство, смена пароля, гео.
3. **Сеть получателей** — возраст счёта, сколько разных людей перевели ему за 24 ч (дроп = молодой счёт + много отправителей), база жалоб.
4. **Текст комментария** (RU + KZ) — «безопасный счёт», «код из смс», «предоплата», «USDT доход», «қауіпсіз шот»…

### AI-слой
- **Isolation Forest** (с нуля) — поведенческие аномалии без разметки.
- **Обучаемая модель** (логистическая регрессия) — предобучена на архиве кейсов и **дообучается на каждом решении аналитика**.
- **NLP-модель** (Naive Bayes, RU + KZ) — ловит новые формулировки мошенников, которых нет в списке фраз.
- **AI-проверка сообщений и звонков** на **Claude** (`claude-opus-5-5`, структурированный ответ на русском и казахском). Без ключа API автоматически работает локальная модель — демо никогда не ломается.

**Объяснимость:** каждое решение = список причин с вкладом в баллы. Клиент видит их человеческим языком, аналитик — в карточке.

**Сетевой эффект:** аналитик помечает операцию как мошенничество → получатель уходит в базу → **все** следующие клиенты защищены автоматически.

## Запуск
Нужен Node.js 18+.
```bash
npm install
npm start
```
`npm install` ставит только официальный SDK Anthropic (необязательная зависимость). Без него и без ключа всё работает, AI-проверка сообщений использует локальную модель. Чтобы включить Claude:
```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```
- http://localhost:3000 — о проекте
- http://localhost:3000/client.html — мобильный банк глазами клиента
- http://localhost:3000/dashboard.html — антифрод-центр банка

```bash
npm run eval
```
Офлайн-оценка качества: типовые и замаскированные атаки, сравнение «правила» vs «+ обучаемая модель», точность NLP.

## Сценарий демо для жюри (3 минуты)
1. **Клиент → «Обычный перевод»** → проходит мгновенно (score ~0). «Честные клиенты не замечают защиты».
2. **«Служба безопасности банка»** → HOLD 90+. Показать справа «Что видит банк»: звонок + свежий счёт + дроп + ML.
3. **«Новый получатель (честно)»** или **OLX** → экран-предупреждение: причины, вопросы, таймер. Ответить «Да, мне звонят» → эскалация в HOLD.
4. **Антифрод-центр → «Запустить поток»**, нажать **«🕸 Сеть дропов»** → видно, как счёт набирает отправителей и становится «ДРОП».
5. Открыть операцию → **«Мошенничество → в базу»** → счётчик «Самообучение» растёт; повторить перевод на этот счёт у клиента → мгновенный HOLD.
6. Клиент → блок **«🤖 AI-проверка сообщения»** → пример «Мама, новый номер» → вердикт и объяснение на русском и казахском.
7. KPI: «Сохранено денег», recall/FPR, 0.0x мс на решение.

## Метрики (`npm run eval`)
Тест: 3 000 честных переводов, 440 типовых и 200 **замаскированных** атак (старые дроп-счета, нет сигнала звонка, обычный комментарий). Обучаемая модель предобучена на **другом** синтетическом мире — без утечки.

| | Правила + iForest | + обучаемая модель |
|---|---|---|
| Типовые атаки: выявлено | 100% | 100% |
| Замаскированные: выявлено | 88,0% | **92,0%** |
| Замаскированные: задержано | 48,5% | **73,0%** |
| Честные: мягкое предупреждение | 2,1% | 2,1% |
| Честные: заблокировано | 0% | **0%** |

NLP (Naive Bayes), leave-one-out на 71 тексте RU/KZ: точность **81,7%**. Время решения < 1 мс.

⚠️ Честно: данные синтетические. На реальных данных банка веса и пороги калибруются на истории — это первый шаг пилота.

## Стек
| Слой | Технология | Зачем |
|---|---|---|
| Бэкенд | **Node.js** (встроенный `http`), 0 зависимостей | запуск одной командой на любом ноутбуке |
| Real-time | **Server-Sent Events** | лента операций в дашборде без перезагрузки |
| ML | **Isolation Forest** на чистом JS | поиск аномалий без размеченных данных |
| ML | **Логистическая регрессия** (SGD, онлайн) | обучение на решениях аналитиков |
| NLP | **Naive Bayes** RU/KZ | новые формулировки мошенников |
| LLM | **Claude** через `@anthropic-ai/sdk` (необязательно) | проверка SMS, сообщений и звонков |
| Правила / NLP | JS + Unicode-regex (RU/KZ) | объяснимые решения, детект фраз мошенников |
| Сетевой анализ | граф «отправитель → получатель» за 24 ч | выявление дропов |
| Фронтенд | **HTML + CSS + vanilla JS** | клиентское приложение и дашборд |
| Данные | синтетический генератор (seed) + симулятор атак | демо и оценка recall/FPR |

## Архитектура
```
server.js              HTTP API + SSE (поток событий в дашборд), без зависимостей
engine/risk.js         риск-движок: признаки, правила, скоринг, решения, обратная связь
engine/isoforest.js    Isolation Forest с нуля
engine/text.js         детектор мошеннических фраз RU/KZ
engine/nlp.js          Naive Bayes + размеченный корпус RU/KZ
engine/supervised.js   обучаемая модель (логистическая регрессия), дообучение на решениях аналитика
engine/ai.js           AI-проверка сообщений: Claude или локальный режим
engine/data.js         синтетические клиенты, счета, дропы, история
engine/simulator.js    поток операций, 6 типовых и 4 замаскированные атаки, предобучение модели
public/                лендинг, клиент, дашборд (vanilla JS)
scripts/evaluate.js    офлайн-оценка качества
```

### API
| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/transfer/check` | оценить перевод → score, decision, reasons |
| POST | `/api/transfer/confirm` | ответ клиента на предупреждение (cancel / proceed + ответы) |
| POST | `/api/review` | решение аналитика fraud / legit (дообучает модель) |
| POST | `/api/analyze-message` | AI-проверка текста сообщения или звонка |
| GET | `/api/stats` · `/api/transactions` · `/api/accounts/suspicious` | данные дашборда |
| GET | `/api/stream` | SSE-поток операций |
